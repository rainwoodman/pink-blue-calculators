# Cute Calculators (Pink & Blue) 🎀 ❄️

Aesthetic, tactile calculators built with Node.js and modern vanilla HTML5 / CSS3 / JavaScript.

## Features

- **🌸 Pink Berry Calculator (Port 3000)**: Cute pastel pink aesthetics, 3D bubbly buttons, floating sparkles, and soft audio tones.
- **❄️ Blue Frost Calculator (Port 4000)**: Cool cyan and sky blue gradient design, diamond badges, and crystal theme.
- **✨ Features**:
  - Full arithmetic operations (`+`, `-`, `×`, `÷`, `%`).
  - Web Audio synthesizer generating cute audio clicks and chimes (with toggle 🔔/🔕).
  - Dual-line LCD display with calculation history.
  - Complete physical keyboard support.
  - Zero heavy frontend dependencies.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16+)

### Running the Calculators

Run the Pink Calculator on port 3000:
```bash
node server.js
```

Run the Blue Calculator on port 4000:
```bash
node server-blue.js
```

Open your browser to:
- Pink Calculator: `http://localhost:3000`
- Blue Calculator: `http://localhost:4000`
